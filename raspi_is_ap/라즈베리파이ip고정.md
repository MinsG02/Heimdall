1단계: 라즈베리 파이 핫스팟 켜기
라즈베리 파이 터미널에 아래 명령어를 그대로 입력합니다.

Bash
sudo nmcli device wifi hotspot ifname wlan0 ssid Heimdall_JEW password 00000000
이 명령어가 성공하면 라즈베리 파이의 IP는 10.42.0.1로 완전히 고정됩니다.

2단계: ESP32 코드 수정 및 업로드
ESP32가 스마트폰 대신 라즈베리 파이 핫스팟에 붙도록 코드 상단의 설정을 아래처럼 바꿉니다.

C
// ================= [★ 사용자 설정] =================
#define MY_NODE_ID      "NODE_1"          // 1~5번 노드에 맞춰 변경
#define STATIC_IP_ADDR  "10.42.0.51"      // 노드별로 51, 52, 53, 54, 55 부여

// 네트워크 설정
#define WIFI_SSID       "Heimdall_JEW"
#define WIFI_PASS       "00000000"
#define GATEWAY_ADDR    "10.42.0.1"       // 라파 핫스팟 IP
#define NETMASK_ADDR    "255.255.255.0"
#define RPI_IP_ADDR     "10.42.0.1"       // 데이터 보낼 라파 목적지 IP
// ====================================================
수정한 코드를 5개의 노드에 각각 업로드합니다.

3단계: 노트북 연결 및 VNC 접속
스마트폰과 노트북을 USB 케이블로 연결하고 스마트폰에서 'USB 테더링'을 켭니다. (노트북 인터넷 확보용)

노트북의 와이파이를 켜고 Heimdall_JEW에 연결합니다.

노트북에서 UltraVNC Viewer를 실행하고 서버 주소에 10.42.0.1을 입력해 접속합니다.

이제 전원을 껐다 켜도 라파와 노드들의 IP는 절대 바뀌지 않습니다.

📌 1단계 명령어의 와이파이 이름과 비밀번호를 Heimdall_JEW 및 00000000으로 갱신했습니다.

📌 2단계 코드의 접속 SSID와 PASS를 동일하게 수정했습니다.

📌 3단계 노트북 연결 와이파이 대상을 갱신했습니다.
