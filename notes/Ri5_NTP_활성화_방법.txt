1단계: Chrony(NTP 서버 프로그램) 설치 및 설정
가장 쉽고 강력한 chrony를 설치해서 설정합니다.

설치 (이미 있어도 업데이트 됩니다)

Bash
sudo apt update
sudo apt install chrony -y

==============================

설정 파일 열기

Bash
sudo nano /etc/chrony/chrony.conf

==============================

내용 수정 (제일 중요!) 파일 안에서 아래 두 줄을 찾거나(없으면 맨 아래에 추가), 주석(#)을 풀어주세요.

[1] 누구에게 시간을 줄 것인가? (Heimdall_Net에 연결된 모든 기기 허용)
allow 0.0.0.0/0
(원래는 allow 192.168.x.0/24 처럼 IP 대역을 적어야 하지만, 지금은 테스트니까 모든 IP 허용으로 풉니다.)

[2] 인터넷이 끊겨도 내 시간을 믿어라! (폐쇄망 필수 설정)
local stratum 10
(이게 없으면 라즈베리파이가 인터넷 연결 안 됐을 때 "나도 시간 몰라" 하면서 ESP32 요청을 무시해버립니다.)

저장하고 나오기: Ctrl + O (엔터), Ctrl + X

==============================

2단계: 서버 재시작
설정을 바꿨으니 프로그램을 재시작합니다.

sudo systemctl restart chrony

==============================

3단계: IP 주소 재확인 (ESP32 코드)
ESP32 코드 맨 위에 있는 **RPI_IP_ADDR**가 현재 라즈베리파이의 IP와 정확히 일치하는지 확인해야 합니다.

라즈베리파이에서 확인:

hostname -I
(여기서 나온 IP, 예를 들어 192.168.50.1 같은 주소가 ESP32 코드에 그대로 있어야 합니다.) <- 이건 다를 수 있음
