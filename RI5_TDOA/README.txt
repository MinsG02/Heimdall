[1] 라즈베리 파이 : NTP 서버 설정
먼저 모든 동기 기준은 라즈베리파이5가 마스터기 때문에 동기서비스를 제공할 NTP 서비스를 설치해야함

-NTP  서비스 설치 : 
sudo apt update
sudo apt install ntp -y

- 설정 변경 : /etc/ntp.conf 파일을 열어 로컬 네트워크 기기들이 접속할 수 있게 허용할 수 있도록 수정
# /etc/ntp.conf 파일 하단에 추가
restrict 192.168.4.0 mask 255.255.255.0 nomodify notrap
